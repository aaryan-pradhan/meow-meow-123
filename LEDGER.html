Every entry has a [C++ | Python] switch above its code. One click flips the whole page, and the choice is remembered. Each Python version is a line-for-line translation that follows the rules below, so you can think in C++ and read off the Python. The translations have not been run.

long long, intintPython ints never overflow, so there's no LL suffix and no casts.
a / b (ints)a // bA single / gives a float. Python's // and % round toward −∞: -7 // 2 = -4 and -7 % 3 = 2, where C++ gives -3 and -1.
&& || ! i++and or not i += 1Python has no ++ or --. Write v[i++] as two lines.
for (i = a; i < b; i += s)for i in range(a, b, s):range stops before b. For i <= n use range(n + 1); for counting down use range(n - 1, -1, -1).
vector<ll> v(n, x)v = [x] * n2D: [[x] * m for _ in range(n)]. Never [[x] * m] * n, which is n references to one row.
pair / array<ll,3>tuple (a, b).fr → [0], .sc → [1]. Tuples compare like pairs. Unpack with a, b = p.
sort(v.begin(), v.end(), cmp)v.sort(key=lambda t: (t[0], -t[1]))Python sorts by a key, not a comparator. "Descending on a field" means negating it in the key.
map / unordered_mapdictm[k]++ becomes m[k] = m.get(k, 0) + 1. Reading a missing key with [] raises, where C++ inserts 0. find → k in m.
set / multiset, lower/upper_boundsorted list + bisect_left / bisect_right, insortThe stdlib has no balanced BST, so insert and erase are O(n). Each such spot is marked with a ponytail comment.
stack / queue / dequelist / collections.dequestack: append, pop(), [-1]. queue: append, popleft().
priority_queue<.., greater<>>heapq.heappush / heappopheapq is a min-heap, so greater<> is the default. For a max-heap, push negated values.
