Recognition rules

The judgment calls that separate these problems from each other.

1

To find the middle, use slow and fast pointers, and choose where fast starts. fast = head->next gives the first middle (Merge Sort). fast = head with a guarded double step gives the second middle (Reorder List I).

2

If you need to walk backwards, reverse that part. The same three-pointer reverse appears in Reorder List I (second half) and Reverse Nodes in k-Group (each group).

3

Cut before you recurse or reverse. mid->next = nullptr (Merge Sort, Reorder List I) and tail->next = nullptr (k-Group) give the helper a finite list. Splice afterwards.

4

If the head might change, start from a dummy node. See the merge in Merge Sort and the group splicing in k-Group.

1 · Split & merge

Find the middle, cut there, work on the halves independently, and then zip them back together. The zip is either a comparison merge or a strict alternation.

Merge Sort Linked List

\(O(N \log N)\)
The ask

Question. You are given the head of a singly linked list with \(N\) nodes. Sort the list by value in \(O(N \log N)\) time using merge sort, and return the new head.

Input
The list's head pointer.
Output
The head of the sorted list.
Limits
\(0 \le N \le 10^5,\ \ 0 \le \text{value} \le 10^9\)
Sample
[2] → [2]; [1,3,6,1,7] → [1,1,3,6,7]
Breakdown
  1. Split the list \(L\) at its middle into \(A\) (first \(\lceil N/2 \rceil\) nodes) and \(B\) (the rest), sort each, and merge: \[ \text{sort}(L) = \text{merge}\big(\text{sort}(A),\ \text{sort}(B)\big), \qquad \text{sort}(L) = L \ \text{ if } N \le 1 \]
  2. Merging two sorted lists takes the smaller head each time, so it costs \(|A| + |B|\) steps. Finding the middle with slow/fast pointers is also \(O(N)\). So \[ T(N) = 2\,T(N/2) + O(N) \;\Longrightarrow\; T(N) = O(N \log N) \]
  3. Simplest form: recursion depth is \(\log_2 N\), so the extra space is the \(O(\log N)\) call stack; no array is used.
Key observations
  1. There is no index to split on, so slow and fast pointers find the middle in one pass.
  2. Starting fast = head->next lands on the first middle, so a 2-node list splits \(1 \mid 1\).
  3. The merge joins two sorted lists behind a dummy node, and the leftover side is attached whole.
Brute force → why it dies
naiveInsertion sort on the list.
cost\(O(N^2)\)
dies at\(N = 10^5\) gives \(10^{10}\). Copying to an array and sorting it breaks the "links only" rule.
thereforeMerge sort on links: \(O(N \log N)\) time, \(O(\log N)\) stack.
Diagram
Implementation

mergesort has the base case, then findMid, then cuts with mid->next = nullptr, recurses and merges. The merge moves temp along the chosen side. The two trailing while loops walk the leftover side node by node, where one splice would also work.

// Problem: Sort a Linked List (Merge Sort)
// Pattern: divide and conquer — split at midpoint, recurse, merge two sorted lists
// Time: O(N log N)  Space: O(log N) recursion stack
//
// Sort a singly linked list in O(N log N) using merge sort. Return the new head.
//
// Constraints: 0 ≤ N ≤ 1e5, 0 ≤ node value ≤ 1e9.
//
// Example:
//     [2]           -> [2]
//         [1,3,6,1,7]   -> [1,1,3,6,7]

#include <iostream>
#include <vector>
using namespace std;

struct ListNode {
    int val;
    ListNode *next;
    ListNode() : val(0), next(nullptr) {}
    ListNode(int x) : val(x), next(nullptr) {}
    ListNode(int x, ListNode *next) : val(x), next(next) {}
};

ListNode* findMid(ListNode* head) {
    ListNode* slow = head;
    ListNode* fast = head->next;

    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
    }

    return slow;
}

ListNode* merge(ListNode* left, ListNode* right) {
    if (!left) return right;
    if (!right) return left;

    ListNode* dummy = new ListNode(-1);
    ListNode* temp = dummy;
    while (left && right) {
        if (left->val < right->val) {
            temp->next = left;
            temp = left;
            left = left->next;
        } else {
            temp->next = right;
            temp = right;
            right = right->next;
        }
    }

    while (left) {
        temp->next = left;
        temp = left;
        left = left->next;
    }

    while (right) {
        temp->next = right;
        temp = right;
        right = right->next;
    }

    return dummy->next;
}

ListNode* mergesort(ListNode* head) {
    if (head == nullptr || head->next == nullptr) {
        return head;
    }

    ListNode* mid = findMid(head);

    ListNode* left = head;
    ListNode* right = mid->next;
    mid->next = nullptr;

    left = mergesort(left);
    right = mergesort(right);

    return merge(left, right);
}

ListNode* GetList(vector<int>& num) {
    ListNode* head = nullptr;
    ListNode* cur = nullptr;
    for (int x : num) {
        ListNode* temp = new ListNode(x);
        if (!cur) { head = cur = temp; }
        else { cur->next = temp; cur = temp; }
    }
    return head;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(0); cout.tie(0);

    int n; cin >> n;
    vector<int> num(n);
    for (int i = 0; i < n; i++) cin >> num[i];

    ListNode* head = GetList(num);
    head = mergesort(head);

    while (head) { cout << head->val << " "; head = head->next; }
    cout << "\n";
    return 0;
}

            temp.next = left
            temp = left

            temp = right
            right = right.next

        temp = right

    left = head
    right = mid.next

Reorder List I

\(O(N)\)
The ask

Question. You are given the head of a singly linked list \(L_1 \to L_2 \to \dots \to L_n\). Reorder it in place to \(L_1 \to L_n \to L_2 \to L_{n-1} \to L_3 \to L_{n-2} \to \dots\). You may only change links, not node values.

Input
The list's head pointer.
Output
The same nodes, relinked.
Limits
\(0 \le n \le 10^6,\ \ 0 \le \text{value} \le 10^9\)
Sample
[1,2,3,4] → [1,4,2,3]; [1,2,3,4,5] → [1,5,2,4,3]
Breakdown
  1. Let \(h = \lceil n/2 \rceil\). Split into the first half \(F = (L_1, \dots, L_h)\) and the second half \(S = (L_{h+1}, \dots, L_n)\). Then \(|F| - |S| \in \{0, 1\}\).
  2. The target takes nodes from the back of \(S\) first, so reverse it: \[ R = \text{reverse}(S) = (L_n, L_{n-1}, \dots, L_{h+1}) \]
  3. Simplest form: alternate \(F\) and \(R\): \[ F_1, R_1, F_2, R_2, \dots \;=\; L_1, L_n, L_2, L_{n-1}, \dots \] Stop when \(R\) runs out. If \(n\) is odd, \(F\) has one extra node, which stays attached at the end.
Key observations
  1. The tail side has to be walked backwards, so reverse the second half.
  2. Split at the second middle. The first half is then as long as the second, or one longer.
  3. Interleave while second is not null. The leftover node of the first half stays attached automatically.
Brute force → why it dies
naiveFor each step, walk to the current tail and move it.
cost\(O(n^2)\)
dies at\(n = 10^6\) gives about \(10^{12}\). An array of node pointers fixes the time but costs \(O(n)\) space.
thereforeSplit, reverse, interleave: \(O(n)\) time, \(O(1)\) space.
Diagram
Implementation

middleNode advances slow only after a successful first step of fast, which lands on the second middle. Each merge round saves both next pointers before overwriting either.

// Problem: Reorder List I
// Pattern: split + reverse second half + merge alternately
// Time: O(N)  Space: O(1)
//
// Given the head of a singly linked list, reorder it in place from
// L1 -> L2 -> ... -> Ln to L1 -> Ln -> L2 -> Ln-1 -> L3 -> Ln-2 -> ....
// Node values may not be changed — only links may be rewired.
//
// Constraints: 0 ≤ length ≤ 1e6, 0 ≤ node value ≤ 1e9.
//
// Example:
//     [3]           -> [3]
//         [1,2,3,4]     -> [1,4,2,3]
//         [1,2,3,4,5]   -> [1,5,2,4,3]

#include <iostream>
#include <vector>
using namespace std;

struct ListNode {
    int val;
    ListNode *next;
    ListNode() : val(0), next(nullptr) {}
    ListNode(int x) : val(x), next(nullptr) {}
    ListNode(int x, ListNode *next) : val(x), next(next) {}
};

ListNode* reverseList(ListNode* head) {
    ListNode* prev = NULL;
    ListNode* cur = head;
    ListNode* next_ = NULL;

    while (cur != NULL) {
        next_ = cur->next;
        cur->next = prev;
        prev = cur;
        cur = next_;
    }
    return prev;
}

ListNode* middleNode(ListNode* head) {
    ListNode* slow = head;
    ListNode* fast = head;

    while (fast) {
        fast = fast->next;
        if (fast) {
            slow = slow->next;
            fast = fast->next;
        }
    }
    return slow;
}

void reorderList(ListNode* head) {
    if (!head || !head->next) return;

    ListNode* mid = middleNode(head);
    ListNode* second = mid->next;
    mid->next = nullptr;
    second = reverseList(second);

    ListNode* first = head;
    while (second) {
        ListNode* tmp1 = first->next;
        ListNode* tmp2 = second->next;
        first->next = second;
        second->next = tmp1;
        first = tmp1;
        second = tmp2;
    }
}

ListNode* GetList(vector<int>& num) {
    ListNode* head = nullptr;
    ListNode* cur = nullptr;
    for (int x : num) {
        ListNode* temp = new ListNode(x);
        if (!cur) { head = cur = temp; }
        else { cur->next = temp; cur = temp; }
    }
    return head;
}

    ios_base::sync_with_stdio(false);

2 · Group reversal

Reverse fixed-size pieces and splice each one back between the previous group's tail and the next group's head. A dummy node makes the first group behave like the rest.

Reverse Nodes in k-Group

\(O(N)\)
The ask

Question. You are given a singly linked list with \(N\) nodes and an integer \(K\) that divides \(N\). Reverse the nodes in each consecutive group of \(K\), and return the new head.

Input
The list's head pointer and \(K\).
Output
The head of the relinked list.
Limits
\(1 \le N \le 10^6,\ \ 1 \le K \le N,\ \ K \mid N,\ \ 0 \le \text{value} \le 10^9\)
Sample
[1,2,3,4,5,6], \(K = 3\) → [3,2,1,6,5,4]; [1,3,2], \(K = 3\) → [2,3,1]
Breakdown
  1. Number the groups \(g = 0, 1, \dots, N/K - 1\). Group \(g\) is the nodes at positions \(gK + 1, \dots, gK + K\).
  2. Each group is reversed on its own, and the groups keep their order: \[ \text{prev} \to [\,h, \dots, t\,] \to \text{next} \quad \Longrightarrow \quad \text{prev} \to [\,t, \dots, h\,] \to \text{next} \]
  3. Simplest form: for each group, walk \(K - 1\) steps to its tail, cut it off, reverse it, then reconnect: \(\text{prev} \to t\) and \(h \to \text{next}\). The old head \(h\) becomes the new \(\text{prev}\).
Key observations
  1. Walk \(K - 1\) steps to the group's tail, save tail->next, and cut.
  2. After reversing, the old head is the group's last node.
  3. Reconnect with prev->next = newHead and head->next = nextGroup, then set prev = head.
  4. \(K = 1\) returns early, although the loop would also handle it.
Brute force → why it dies
naiveCopy the values into an array, reverse the chunks, write them back.
cost\(O(N)\) time, \(O(N)\) extra space.
dies atNot on time at \(N = 10^6\), but it breaks the \(O(1)\)-space, relink-the-nodes requirement.
thereforeCut, reverse, reconnect each group: \(O(N)\) time, \(O(1)\) space.
Diagram
Implementation

reverse is the plain three-pointer loop on the cut-off group. In reverseList, after the reversal head still points to the same node, which is now the group's tail. So the same variable serves as both the splice point and the next prev.

// Problem: Reverse Nodes in k-Group
// Pattern: group-bounded in-place reversal
// Time: O(N)  Space: O(1)
//
// Given a singly linked list of length N and an integer K, reverse the nodes
// in groups of size K and return the head. K divides N exactly (no partial
// final group to worry about).
//
// Constraints: 1 ≤ N ≤ 1e6, 1 ≤ K ≤ N, 0 ≤ node values ≤ 1e9, N % K == 0.
//
// Example:
//     [1,2,3,4,5,6], K=3 -> [3,2,1,6,5,4]
//         [1,3,2],       K=3 -> [2,3,1]

#include <iostream>
#include <vector>
using namespace std;

struct ListNode {
    int val;
    ListNode *next;
    ListNode() : val(0), next(nullptr) {}
    ListNode(int x) : val(x), next(nullptr) {}
    ListNode(int x, ListNode *next) : val(x), next(next) {}
};

ListNode* reverse(ListNode* head) {
    ListNode* prev = NULL;
    ListNode* cur = head;
    ListNode* next_ = NULL;

    while (cur != NULL) {
        next_ = cur->next;
        cur->next = prev;
        prev = cur;
        cur = next_;
    }
    return prev;
}

ListNode* reverseList(ListNode* head, int K) {
    if (head == nullptr || K == 1) return head;

    ListNode* dummy = new ListNode(0, head);
    ListNode* prev = dummy;

    while (head) {
        ListNode* tail = head;
        for (int i = 1; i < K; i++) tail = tail->next;

        ListNode* nextGroup = tail->next;
        tail->next = nullptr;
        ListNode* newHead = reverse(head);

        prev->next = newHead;
        head->next = nextGroup;

        prev = head;
        head = nextGroup;
    }
    return dummy->next;
}

ListNode* GetList(vector<int>& num) {
    ListNode* head = nullptr;
    ListNode* cur = nullptr;
    for (int x : num) {
        ListNode* temp = new ListNode(x);
        if (!cur) { head = cur = temp; }
        else { cur->next = temp; cur = temp; }
    }
    return head;
}
